# Brief Intake Gate (v2.3)

ด่านบังคับก่อนเขียนโค้ด UI ทุกงานที่เป็น new / revamp / like
ข้ามได้เฉพาะ: ผู้ใช้ระบุเป้าหมายชัดเจนแล้วสั่ง "ลุยเลย" หรือ "skip intake" / แก้งานระดับ "จุดเล็ก" (แตะไม่เกิน 1 ไฟล์ และไม่เปลี่ยน layout/สีหลัก/ฟอนต์)

> [!IMPORTANT]
> **กฎเหล็กเรื่องเป้าหมายงาน (The Target Subject Invariant):**
> - **นิยามของ "ระบุเป้าหมายแล้ว":** มีอย่างใดอย่างหนึ่ง: มีไฟล์/โค้ดเดิมแนบมา, มีชนิดงานที่ระบุชัดเจน (เช่น landing page, dashboard, เว็บพอร์ต, สไลด์ ฯลฯ), หรือมีบริบทงานก่อนหน้าในบทสนทนาที่เจาะจงชัดเจน
> - **หากยังไม่ระบุเป้าหมาย:** ห้ามเดาโจทย์ ห้ามแต่งเนื้อหาเอง และห้ามกระโดดเขียนโค้ดเด็ดขาด
> - **การถามเพื่อคลายความกำกวม (One-Turn Max 3 Questions):**
>   - บรรทัดแรกต้องประกาศ `โหมด: ...` เสมอ
>   - ถามคำถามปลายเปิดโดย**ไม่ใส่ตัวอย่างนำทาง** และใช้ภาษาเดียวกับผู้ใช้: *"จะให้สร้างหรือแก้อะไรครับ?"*
>   - หากมีช่อง brief อื่นที่ขาด ให้รวมถามในข้อความเดียวกัน (รวมกันไม่เกิน 3 ข้อ)
>   - หากผู้ใช้สั่ง "ลุยเลย" แต่ยังไม่ระบุเป้าหมาย: ให้ถามข้อเดียวสั้นๆ เท่านั้นว่า *"จะให้สร้างหรือแก้อะไรครับ?"* (เมื่อผู้ใช้ตอบ จึงล็อก Direction A แล้วลุยทันที)
>   - หากผู้ใช้ตอบว่า "อะไรก็ได้" หรือ "ตามสบาย": ให้เลือกชนิดงานทั่วไป 1 อย่าง ประกาศเป็น "สมมติฐาน: ..." บรรทัดเดียว แล้วไปต่อได้ทันที

---

## 0. ล็อกโหมด (Single Source of Truth)

คำสั่งที่ผู้ใช้พิมพ์ (`new`, `revamp`, `like`) ชนะการจับคำในข้อความเสมอ ถ้าไม่ได้พิมพ์โหมด ให้อนุมานตามลำดับนี้:

1. **อ้างอิงแบรนด์หรือสไตล์ (`like`):**
   - มี URL หรือชื่อแบรนด์ที่มีคำขยายว่า "เหมือน", "สไตล์", "แบบ", "อ้างอิง", "like", "inspired by" -> `like`
   - หากผู้ใช้ระบุ "ทำใหม่หมดเหมือน Stripe" ให้ถือเป็น `like` (สร้างใหม่โดยอิงสไตล์แบรนด์ ไม่อิงไฟล์เดิม)
   - หากมีไฟล์เดิมแนบมากับ `like` (และไม่ได้สั่งทำใหม่หมด): ให้คง Business Logic และ Props เดิมไว้ เปลี่ยนเฉพาะ Visual Layer
   - คำสั่ง Preset: `/medesign apple`, `tesla`, `metha` หรือ `/medesign <brand>` ถือเป็น `like` ที่มีสเปกพร้อมใช้ (ข้ามการค้นหาโทเค็น แต่ยังคงต้องรู้เป้าหมายงานตามกฎเหล็กด้านบน และตรวจ §1 เรื่องข้อจำกัด โดยรวมถามในรอบเดียว)
   - *ข้อยกเว้น:* หากชื่อแบรนด์เป็นโจทย์ของงาน (เช่น "ทำเว็บขายรองเท้า Nike") ไม่ใช่สไตล์อ้างอิง ให้จัดเป็น `new`

2. **มีไฟล์/โค้ดเดิมแนบมา (`revamp`):**
   - มีไฟล์หรือโค้ดเดิมแนบมา และไม่ได้ระบุว่า "ทำใหม่หมด" -> `revamp`

3. **สร้างใหม่จากศูนย์ (`new`):**
   - ผู้ใช้ระบุว่า "ทำใหม่หมด" / "start over" หรือไม่มีทั้งไฟล์และแบรนด์อ้างอิง -> `new`

บรรทัดแรกของคำตอบต้องประกาศ `โหมด: new` (หรือ `revamp` / `like`) เสมอ ห้ามถามเรื่องโหมดซ้ำ และห้ามใส่วงเล็บหรือข้อความอื่นต่อท้าย (เพื่อให้ตรวจจับตรงกัน)
อนุมานไม่ได้จริงๆ ถามข้อเดียวเท่านั้น: "งานนี้คือ สร้างใหม่ / แก้ของเดิม / ทำตามเว็บอ้างอิง?"

**เส้นทางของแต่ละโหมด:**
- `new` -> `references/design-core.md` -> `references/quality-gate.md`
- `revamp` -> `references/redesign-audit.md` -> `references/quality-gate.md`
- `like`:
  - หากเป็นแบรนด์ที่มีสเปกใน `presets/<name>/` หรือ `references/brand-design-tokens.md` (เฉพาะแบรนด์ที่มีสเปกโทเค็นกำกับ) -> อ่านสเปกก่อน -> เสนอ Direction A/B ได้ทันที
  - **like ที่ไม่มีสเปกในเครื่อง:**
    1. ห้ามแต่งตัวเลขหรือค่าสีขึ้นเองจากความจำเด็ดขาด (Anti-Hallucination)
    2. ใช้ภาษาธรรมชาติสื่อสารกับผู้ใช้ (ห้ามหลุดชื่อกฎภายใน เช่น Token Spec Hierarchy หรือ Anti-Hallucination Invariant) เช่น *"ผมไม่มีไฟล์สเปกของแบรนด์นี้ในเครื่อง จะดึงสดจากเว็บจริงให้แทนครับ"*
    3. หากเข้าถึงอินเทอร์เน็ตได้: ให้สกัดจากเว็บจริงผ่าน `/medesign extract <url>` โดยอัตโนมัติ (เลือกหน้าหลักเป็นค่าเริ่มต้น ไม่ต้องถามขออนุญาตผู้ใช้) เมื่อได้สเปกแล้วจึงเสนอ 2 ทิศทาง A/B
    4. หากเข้าอินเทอร์เน็ตไม่ได้ หรือไม่มีเครื่องมือตรวจจับ: แจ้งผู้ใช้ตามตรงว่าเข้าเว็บไม่ได้ และขอ URL หรือภาพหน้าจอ ห้ามแอบใส่ค่าสีจากความจำ
  - จากนั้นไปที่ `references/design-core.md` -> `references/quality-gate.md` (ห้ามเข้า `audit`)

## 1. ตรวจ Brief 5 ช่อง (One-Roundtrip Alignment)

เป้าหมาย+ผู้ใช้ / อารมณ์ 3 คำ / อ้างอิง (ยืมอะไร ไม่ยืมอะไร) / ไม่เอา / ข้อจำกัด (stack, อุปกรณ์, ภาษา, สิ่งที่ห้ามแตะ)
- ช่องไหนผู้ใช้ตอบแล้ว ใช้เลย ห้ามถามซ้ำ และห้ามถามสิ่งที่อ่านได้จากโค้ดที่แนบ
- **One-Shot Alignment:**
  - หากรู้เป้าหมายและ Brief ครบแล้ว: เสนอ 2 ทิศทาง (§2) ทันทีในข้อความแรก
  - หากขาด: รวมคำถามเป้าหมายและ Brief ที่ขาดถามในข้อความเดียว ไม่เกิน 3 คำถาม พร้อมเสนอทิศทางชั่วคราวให้ตอบ "ok" หรือ "ลุยเลย" ได้ในรอบเดียว
  - การตอบ **"ok"** ต่อทิศทางชั่วคราว มีความหมายเท่ากับ: `ยอมรับค่าเริ่มต้นที่เสนอ + เลือก Direction A`
- ใช้ `ask_question` ถ้ามี หากไม่มีให้ถามเป็นข้อความธรรมดาในแชต ถามได้รอบเดียวเท่านั้น

## 2. เสนอ 2 ทิศทาง

Direction A ใกล้ brief ที่สุด / Direction B ต่างอย่างชัดเจน (ต่างกันอย่างน้อย 2 ใน 4: โครง layout, สีหลัก, คู่ฟอนต์, ความหนาแน่น)
แต่ละทิศทางไม่เกิน 5 บรรทัด:
- ชื่อ + อารมณ์ 1 บรรทัด
- Layout และความหนาแน่น
- สี 3 ค่า (hex หรือ oklch) + ฟอนต์ (Latin + ไทย)
- Motion: เลือก 1 ใน 4 Profiles มาตรฐานเท่านั้น (`precision`, `soft-settle`, `spring-settle`, `instant`) ห้ามแต่งชื่อ profile เอง
- เหมาะเมื่อ / เสี่ยงเมื่อ

เพิ่มตามโหมด:
- `revamp`: ระบุ "คงอะไร / เปลี่ยนอะไร"
- `like`: ระบุ "ยืมอะไร / ไม่ยืมอะไร" (A ใกล้ต้นฉบับ, B ตีความใหม่ให้เข้าตัวตนผู้ใช้) ห้ามลอกโลโก้ ข้อความ รูป
- **Hierarchy Rule:** สิ่งที่ผู้ใช้เลือกใน Intake ชนะ Layout Pairing Matrix เสมอ และ Matrix ใช้เฉพาะงาน App/Dashboard/Cockpit (หากเป็น Landing Page/Marketing ให้ใช้ Layout ที่ผู้ใช้เลือก หรือค่าเริ่มต้นใน `references/design-core.md`)

ปิดท้ายด้วย: "เลือก A / B / ผสม (ระบุ) หรือพิมพ์ 'ลุยเลย' (ผมจะใช้ A)"
*(AI สามารถปรับปรุงรายละเอียดทิศทาง A/B ได้ 1 ครั้งหลังได้รับคำตอบจากผู้ใช้)*

## 3. Gate & ทางลัด

- ห้ามเขียนโค้ดหรือสร้างไฟล์จนกว่าผู้ใช้เลือก (หรือสั่ง "ลุยเลย")
- **ลุยเลย Escape Hatch:**
  - เมื่อผู้ใช้ระบุเป้าหมายชัดเจนแล้วสั่ง "ลุยเลย" / "skip intake": ให้ประกาศ `Locked Direction: Direction A` 3 บรรทัด แล้วลงมือเขียนโค้ดทันทีโดยไม่ถามซ้ำ
  - หากสั่ง "ลุยเลย" แต่ยังไม่ระบุเป้าหมายงาน (เช่น `/medesign new ลุยเลย`): ให้ถามข้อความเดียวสั้นๆ ก่อนว่า *"จะให้สร้างหรือแก้อะไรครับ?"* (ไม่ใส่ตัวอย่างชี้นำ) เมื่อผู้ใช้ตอบ จึงล็อก Direction A แล้วลงมือทันที
- เมื่อเลือกแล้ว สรุป "Locked Direction" 3 บรรทัด (บันทึกใน DESIGN.md ถ้ามี) แล้วไป workflow ของโหมด -> `quality-gate.md`

## 4. ข้อห้าม

- ห้ามใช้ `user-profile.json` หรือ DNA ส่วนตัว เว้นแต่ผู้ใช้สั่ง `/medesign auto` หรือ `/medesign metha` เองโดยตรง (ห้ามอนุมานจาก Path โฟลเดอร์ของเครื่อง)
- ห้ามเสนอเกิน 2 ทิศทาง ห้ามถามเกิน 1 รอบ
