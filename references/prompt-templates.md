# เทมเพลตคำสั่ง medesign (คัดลอก แล้วกรอก)

วิธีใช้: เลือก 1 กล่อง ที่ตรงกับงาน แล้วแทนที่ข้อความในวงเล็บ [ ]
บรรทัดแรก (คำสั่ง) ห้ามแก้ เพราะเป็นตัวบอก AI ว่าอยู่โหมดไหน
ไม่รู้จะกรอกอะไร ปล่อยว่างได้ AI จะเสนอให้เลือกเอง / อยากข้ามการถามกลับ ให้เติมท้ายกล่องว่า "ลุยเลย"

## 1. สร้างใหม่จากศูนย์ (ยังไม่มีอะไรเลย)

```
/medesign new
งาน: [เว็บ / แอป / หน้าไหน]
ใครใช้ และให้ทำอะไร: [ ]
อารมณ์ 3 คำ: [เช่น สะอาด น่าเชื่อถือ อบอุ่น]
ไม่เอา: [เช่น สีนีออน, gradient ม่วงฟ้า, การ์ด 3 ใบเรียงเหมือนกัน]
ข้อจำกัด: [stack, มือถือหรือเดสก์ท็อปเป็นหลัก, ภาษา]
เนื้อหาจริง: [แนบมา หรือ "ใช้ placeholder"]
```

## 2. แก้ / รีดีไซน์ของเดิม (มีไฟล์หรือหน้าอยู่แล้ว)

```
/medesign revamp
ไฟล์หรือหน้าที่แก้: [path หรือแนบโค้ด]
ปัญหาที่รู้สึก: [เช่น รก ลำดับความสำคัญไม่ชัด]
คงไว้: [เช่น logic, API, สีแบรนด์ #xxxxxx]
แก้ได้: [layout / สี / ฟอนต์ / spacing / ทั้งหมด]
อารมณ์ใหม่ 3 คำ: [ ]
ไม่เอา: [ ]
```

## 3. ทำตามเว็บดัง / แบรนด์อ้างอิง

```
/medesign like [URL หรือชื่อแบรนด์ เช่น linear.app]
นำไปใช้กับ: [ไฟล์/หน้าของผม หรือ "สร้างใหม่"]
ยืมจากต้นฉบับ: [layout / สี / ฟอนต์ / ความหนาแน่น / motion]
ไม่ยืม: [โลโก้ ข้อความ รูป illustration]
คงของผม: [สีแบรนด์ #xxxxxx, ชื่อ, เนื้อหา]
ไม่เอา: [ ]
```

## สำหรับผู้ดูแล SKILL.md: กฎ routing ที่ต้องเพิ่ม

1. ลำดับความสำคัญ: คำสั่ง `/medesign new`, `revamp`, `like` ที่ผู้ใช้พิมพ์ ชนะตาราง auto-detect ทุกกรณี
2. คำว่า "รีดีไซน์" ในข้อความธรรมดา ห้ามส่งเข้า `audit` อัตโนมัติ ให้ผ่าน `references/brief-intake.md` ข้อ 0 เพื่อล็อกโหมดก่อน
3. `audit` เหลือไว้เป็นเครื่องมือตรวจของเดิมเท่านั้น (เรียกเองด้วย `/medesign audit` หรือถูกเรียกต่อจาก `revamp`)
4. ในตารางใดๆ ห้ามใช้ `|` ในโค้ด ให้เขียน `web หรือ mobile` หรือ `{a,b,c}` แทน
