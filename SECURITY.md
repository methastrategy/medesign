# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.7.x   | :white_check_mark: |
| 1.6.x   | :white_check_mark: |
| < 1.6.0 | :x:                |

## Reporting a Vulnerability

We take the security of ME-DESIGN seriously. If you believe you have found a security vulnerability in ME-DESIGN, please report it responsibly.

### How to Report

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report security vulnerabilities via GitHub's Private Vulnerability Reporting:
1. Navigate to the [Security Advisories](https://github.com/methastrategy/medesign/security/advisories) tab of this repository.
2. Click **Report a vulnerability**.
3. Fill in the details of the issue, including steps to reproduce, impact, and any potential remediation.

### Response Timeline

- **Initial Response:** Within 48 hours of receipt.
- **Triage & Assessment:** Within 7 business days.
- **Fix & Disclosure:** Coordinated release once a patch is tested and verified.

Thank you for helping keep ME-DESIGN and its community secure.
